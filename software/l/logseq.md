## Overview
A block-based outliner where every bullet can be linked, referenced and queried. The daily journal is the default entry point.

## Key Features
- Outliner editing with block references and embeds
- Daily journals and built-in task states (TODO, DOING, DONE)
- Queries across all notes
- Plugin and theme marketplace

## Limitations
- Development of the file-based version has slowed while a database version is being built
- Large graphs can get slow
- Outliner-only editing does not suit long-form writing

## Compared to Alternatives
- **Obsidian:** page-first with a bigger ecosystem but closed source. Logseq is open source and outline-first.
- **Roam Research:** similar model, but Logseq is free and stores files locally.
