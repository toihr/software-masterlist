## Overview
A freeware desktop search utility for Windows by voidtools. It builds a filename index of local drives and returns results instantly while typing.

## Key Features
- Fast filename and path search with wildcards, regex and search operators
- Optional HTTP and ETP servers for searching a machine remotely
- Command-line client (`es.exe`) and an SDK for integration
- Free for personal use; Everything Server site licenses exist for business use

## Limitations
- Windows only
- Searches file and folder names by default, not file contents
- Binaries are freely redistributable but the source is not open

## Compared to Alternatives
- **UltraSearch:** UltraSearch has a larger GUI with content search and optional central indexing; Everything is lighter and focused on names.
